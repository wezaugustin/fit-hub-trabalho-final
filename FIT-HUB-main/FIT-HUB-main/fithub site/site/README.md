# FITHUB — Loja de kits fitness

Projeto acadêmico de e-commerce feito com **HTML, CSS e JavaScript puro** (sem frameworks).

## Funcionalidades
- Vitrine com 15 produtos (imagem, nome, preço, descrição, categoria), filtro por categoria e busca
- Página de produto com escolha de cor, quantidade e produtos relacionados
- Carrinho: adicionar, alterar quantidade, remover e total (salvo no `localStorage`)
- Checkout em 3 etapas: dados, entrega e pagamento
- Pagamento simulado: **crédito (com parcelamento até 12x)**, **débito**, **Pix** (QR Code e copia e cola) e boleto
- Conta de usuário e histórico de compras
- Layout responsivo (desktop e mobile)

## Estrutura
```
index.html   página principal
styles.css   estilos e responsividade
app.js       dados, carrinho, checkout e telas
imagens/     fotos dos produtos e logo
```

## Como executar
Abra o `index.html` no navegador. Não precisa instalar nada.

> Simulação acadêmica: nenhuma cobrança real é feita.
